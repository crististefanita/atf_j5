# Materiale istorice Contract Whist

## Pe scurt

Surse păstrate din verificarea unei aplicații anterioare. Nu sunt module ale reactorului Rentz, nu sunt rulate de lansatorul curent și nu califică regulile noului joc.

## Responsabilitate

Clasele și documentele istorice rămân pentru trasabilitate. Runner-ele anterioare au dependențe proprii care cer recalificare înaintea reutilizării; nu se pornesc ca parte a testării Rentz.
