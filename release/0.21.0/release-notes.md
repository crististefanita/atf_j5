# Noutăți în Rentz Lab 0.21.0

Ediția corectează selectarea classpath-ului Surefire când game-core apare înainte de tf-tests. Un eșec Maven rămâne FAIL, Android JVM apare NOT_RUN, iar agregatul RAG rămâne BLOCKED; raportul Extent păstrează diagnosticul și hash-urile receipt-urilor originale.

Calificarea include 569 de teste Maven, 119 teste Android JVM și cinci jocuri native consecutive pe profil compact. Raportarea Extent leagă fiecare rezultat de commitul sursă și de APK-ul verificat. [Rapoarte și proveniență](reports/README.md)
