# Noutăți în Rentz Lab 0.15.0

La 3–6 jucători, locurile în faza de joc folosesc geometria Whist. În Rentz, cărțile depuse folosesc banda dintre jucători și se suprapun pe rândurile dense.

Calificarea ediției include regresia de componentă, lint și semnarea. E2E este omis la cerere pentru această ediție. [Rapoarte](reports/README.md)
