# Notele ediției 0.30.0

## Joc și prezentare

Scorul și istoricul Android și WEB folosesc prezentatorul comun Rentz, cu Δ pentru punctele mâinii și Σ pentru total. Rentz păstrează ordinea sosirii și un singur jucător cu zero puncte.

## Acceptanță și conservare

Acceptanța Android salvează pachetul izolat preexistent și fișierele sale, le restaurează sub aceeași rezervare și verifică octeții înainte de eliberare. Fluxul Chrome verifică jocurile complete, istoricul și reluarea prin comenzile publice.
