# Notele ediției 0.32.0

## Infrastructură și raportare

Sursa separă intrările întreținute de build-uri și date generate. Guvernanța refuză directorul istoric de date din checkout, iar semnarea folosește identitatea persistentă verificată. Rapoartele Extent folosesc narațiune în engleză și păstrează observațiile originale, capturile și verdictul.

## Acceptanță

Meniul și istoricul folosesc contractele comune de prezentare, cu text normal și separatoare între jucători.

Componentele verifică adaptoarele și bibliotecile comune. Acceptanța nativă execută trei sub-jocuri distincte, cu Rentz primul, apoi verifică restaurarea pachetului izolat. Chrome Android verifică jocuri complete, scor, istoric și reluare pe același graf public de resurse WEB.

## Limite de afișare urmărite

La text mărit, rămân de îmbunătățit rangurile de margine din evantai și împachetarea etichetei actorului. În Chrome compact, barele browserului pot decupa marginea antetului sau a mâinii. [Criteriile UI rămase](../../docs/feedback/ATF_Rentz_UI_ToDo.md) separă aceste observații raster de flow-urile și calculele trecute.
