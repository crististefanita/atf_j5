# Livrarea Rentz Lab

## Pe scurt

Catalogul arată ultima ediție calificată și starea reală a descărcării. Rapoartele originale și copiile de audit rămân în depozitul extern de dovezi.

## Ultima ediție calificată

[Rentz Lab 0.30.0](0.30.0/README.md) este ediția publicată și verificată prin descărcare. APK-ul este disponibil din README-ul principal.

## Organizare

| Zonă | Rol |
|---|---|
| Dosarul ediției calificate | Note, manifest și proveniența verificărilor. |
| Rapoarte | Rulări Extent și receipts păstrate în depozitul extern de audit. |
| Descărcare | Linkul APK apare în README numai după publicare și verificarea asset-ului prin RAG. |

Catalogul surselor păstrează numai ultima ediție calificată; tagurile istorice și dovezile de audit sunt arhivate separat.
