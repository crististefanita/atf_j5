# Rentz Lab 0.2.0

## Pe scurt

Ediția include punctajul mâinii, sugestia AI și reluarea ultimei levate.

- [APK semnat](https://github.com/crististefanita/atf_j5/releases/download/v0.2.0/RentzLab-0.2.0.apk)
- [Checksum SHA-256](https://github.com/crististefanita/atf_j5/releases/download/v0.2.0/RentzLab-0.2.0.apk.sha256)

## Schimbări

- Punctajul mâinii include sub-jocul, contribuțiile și totalurile pe jucător.
- Sugestia AI este disponibilă după dezvăluirea cărților.
- Ultima levată se revede după restart. Animația se încheie la câștigător.
- Chenarele păstrează numele și cele două rânduri de scor la font mărit.
