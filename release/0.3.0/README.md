# Rentz Lab 0.3.0

## Pe scurt

Acest dosar descrie candidatul Android Rentz Lab 0.3.0 și limitele calificării lui. Cât timp starea este DRAFT, nu există un APK de descărcat.

## Stare

**Candidat DRAFT. APK-ul nu a fost încă construit și calificat.** Pagina de descărcare publică rămâne pe ultima ediție publicată până când binarul semnat și copia publică trec verificarea completă.

## Schimbări planificate

- Masa Rentz adaptează spațiul pentru mesele de 3–6 locuri și folosește centrul pentru tabla secvențelor.
- Cărțile legale sunt evidențiate discret; deschiderea și extinderea secvențelor rămân validate de motor.
- Turele automate se afișează pe rând: indicatorul locului devine vizibil înaintea mutării, apoi urmează pauza de 550 ms. Pauza și schimbarea sesiunii invalidează mutările vechi.
- Biblioteca de raportare ATF J23 este folosită de testele proiectului; nu este inclusă în APK-ul produs.

Acestea sunt declarații de candidat, nu afirmații de acceptanță. Rezultatele efective vor fi publicate în dosarul dovezilor numai după calificarea exactă a commitului sursă.
