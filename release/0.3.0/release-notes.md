# Rentz Lab 0.3.0 — candidat

Acest candidat reunește corecțiile de interacțiune ale mesei Rentz: afișarea turei automate înaintea acțiunii, temporizare după primul cadru vizibil, invalidare la schimbarea lifecycle-ului și spațiu adaptat pentru tabla de secvențe. Se califică prin regresia offline, Android JVM și sanity-ul nativ selectat pentru schimbările de interfață.

Lista devine notă de release numai după ce APK-ul 0.3.0 este semnat, identitatea sa este verificată, iar descărcarea publică este confruntată octet cu octet.
