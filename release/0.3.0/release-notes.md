# Rentz Lab 0.3.0

- Adaptare a mesei pentru 3–6 jucători și spațiu central pentru secvențele Rentz.
- Evidențiere discretă a cărților legale și păstrarea identității cărților din proiecția motorului.
- Mutări automate prezentate pe rând după primul cadru vizibil, cu pauză de 550 ms și invalidare la schimbarea sesiunii sau rutei.
- APK Release semnat, nedebuggable, cu hash și certificat verificate înaintea distribuirii.
- Regresie offline, Android JVM, probe native pe pachetul izolat și descărcare publică verificate separat; limitele lor sunt în README-ul versiunii.
