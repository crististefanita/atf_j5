# Noutăți în Rentz Lab 0.23.0

Jocurile noi de secvență Rentz pentru 3–6 jucători pornesc acum de la valet. O sesiune reluată păstrează regula istorică pentru mâna deja distribuită, astfel încât restaurarea să nu schimbe o stare aflată în desfășurare.

Calificarea include teste de componentă pentru alegerea deschizătorului și compatibilitatea reluării, regresia Maven și Android JVM, apoi trei jocuri native consecutive — Rentz, Tricks și Whist — pe profilul compact 720 × 1280, densitate 360 și font 150%.

APK-ul de produs este semnat, `debuggable=false`, `versionName=0.23.0` și `versionCode=27`. Distribuția rămâne limitată la conturile autorizate.
