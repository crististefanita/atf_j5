# Note Rentz Lab 0.28.0

- Istoricul folosește antetele compacte Δ și Σ, fără două puncte; masa și rezultatul păstrează Δ: și Σ:.
- Biblioteca Browser comună rezervă spațiu pentru eticheta turei fără mutarea chenarelor. Adaptorul WEB recalculează șirurile înainte să expună tabla.
- Distribuția APK folosește release-ul public din depozitul Rentz, verificat prin descărcare autentificată și anonimă.

Sursa APK-ului este tagul acestei ediții. Corecția suplimentară de măsurare WEB este livrată separat pe Pages; intrările Android rămân identice cu sursa calificată.
