# Noutăți în Rentz Lab 0.19.0

În Rentz, numai ultimul loc primește zero. Ajutorul prezintă premiile pentru mesele de 3–6 jucători. Istoricul afișează profilul cu care a fost jucată mâna și păstrează ordinea sosirii.

Calificarea include regresia de componentă, cinci jocuri native consecutive pe profilul compact, semnarea și verificarea descărcării autorizate. [Rapoarte](reports/README.md)
