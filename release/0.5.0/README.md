## Calificare

Versiunea a trecut 404 teste Maven și 81 de teste Android JVM. Proba nativă pe pachetul izolat a încheiat trei jocuri consecutive, cu 101 mutări și pasuri auditate independent. Cele 19 checkpoint-uri au acoperit jocul, istoricul scorurilor și reluarea după repornire.
