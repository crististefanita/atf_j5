# Dovezile Rentz Lab 0.5.0

## Pe scurt

Manifestul leagă APK-ul publicat de sursa calificată, probele native și ambele descărcări.

| Probă | Domeniu |
|---|---|
| Componente | 65 de suite și 485 de teste, cu rezultatele reconciliate cu XML-urile Surefire. |
| E2E Android | Rentz și două jocuri de Levate pe pachetul izolat, cu capturi PNG originale inline, scor și reluare după repornire. |
| Build semnat | Semnătura, numărul de versiune și SHA-256 al APK-ului de produs. |
| Distribuție | APK-ul și checksum-ul au fost descărcate prin GitHub autentificat și prin ruta publică fără cont. |
